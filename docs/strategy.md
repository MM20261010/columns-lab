# 事業実験の判断基準 (2026-10-10)

- 初期費用0円、GPT主導で作成し、ユーザーの操作は承認・登録・管理に限定。
- 利益だけを追わず、サイト訪問・Google検索表示回数・クリック数を月次確認。収益0円の月も正直に記録。
- 最初の1～2か月は無理にアフィリエイトを設置しない。広告表示の不透明さを避ける。
- 既存CSV結合は無料競合が多数で、独自性が弱い。列不足の検出・安全な列結合で小さな仮説を検証する。
- 四半期時点で訪問・検索表示ともに乏しければ、同じ方向へ機械的に増産せず市場・価値仮説を見直す。
- 利益・検索順位の単調増加は保証できない。各月に学びとテスト可能な改善仮説を最低1件残す。
