# 事業実験の判断基準（2026-10-12更新）

## 収益・出金の現行方針（本人指示、2026-10-13 16:14以降）

「ゼロから1円」は第三者との正当な取引で確定収益を生んだことを確認する初期マイルストーン。1円の出金や銀行着金は必須ではない。未出金でも正当に確定・記録できた成果を評価する。実需/継続性、GPT主体の低介入、費用/安全、発生・確定・蓄積の検証、長期純利益改善を優先。純利益＋1円は別の利益指標として追い、確定売上だけで利益達成としない。

推定収益、未確定報酬、確定報酬、未出金残高、出金申請額、出金済み額、決済口座の実受取額、銀行実入金額、実測経費、純利益を別記録する。未取得は不明。外貨は原通貨/金額/確定日を残し、円換算の方法/日付/レートが未確認なら円額も不明。未確定・推定値は初期成果にしない。

事業上必要がなければ残高を蓄積できる。最低出金額の高さだけでは大幅に評価を下げない。実需/低介入/安全の採択条件は緩めない。確定報酬から実際に生じた返金/手数料/費用を区別し、将来の換金/出金費は見込み費用として別記録、未発生費を実測経費にしない。手数料控除済み残高から二重に費用を引かない。

登録/採択前に、報酬の期限・失効・休眠、最低出金/費用/方法、終了/規約変更時の残高、日本居住者の受取資格、本人確認/税務/通知の条件を確認。不明を「無期限・安全・日本可」に置き換えない。必要な本人確認/契約/出金/支払は具体的な必要性と影響を示し事前承認、反復転記を本人へ移さない。既存権限の安全な読取り/調査は自律可。

未出金でも税務上の収入計上が必要になり得る。国税庁は原則として収入すべき権利の確定した額を説明し、条件付きの現金主義等もある。個別の所得区分/申告要否/外貨換算は未判定で、少額だから申告不要と断定しない。[国税庁No.2200](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2200.htm)。


安全性・プライバシー・利用者の利益、合法性・規約、初期/追加費用0円、最小権限を必須条件とする。収益モデル選定では人間の反復作業がほぼ不要で、GPTが継続運営できることを最重要条件にする。初収益の速さより再現性・省人化を優先。初期の正当な確定収益、純利益改善、未出金残高、実入金を区別して追う。初期成果に出金は必須でない。

- ココナラの個別確認代行/受託は第一候補から外す。顧客対応/納品/修正を本人へ移す案は、早い収益でも優先しない。
- 条件付き第一候補は無料実用ガイド＋適合するサービス紹介。自動配布の単品デジタル商品を第二候補として比較。CSVや特定業種に固定しない。無料代替が足りる利用者に購入を促さない。
- 需要・集客・案件条件・GPTの安全な通知/定期確認経路が未確認なら、登録/掲載を急がない。現在の閲覧/利益は不明、0に置き換えない。記事/機能/素材の量産はしない。
- 初回、定期、注文ごと、例外時の人間の操作を分け、依頼回数/理由と実測時間を記録する。未測定時間を省人化実績にしない。無償労働を費用0円と混同しない。
- 本人は不可欠な本人確認・契約・重要承認のみ。新規登録/提携/課金/外部投稿/重要公開前に、GPTが具体案・規約/費用・影響・運用/停止方法を準備する。秘密/銀行情報/未承認販売素材を公開GitHubへ置かない。
- GPTの常時監視/無人定期実行は未設定。必要な確認を本人へ押し戻す前提のモデルは採らず、運用経路が成立しない場合は保留/別案にする。
