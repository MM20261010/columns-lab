## 最小の試験データ

a.csv（UTF-8、可能ならBOMあり）:

```csv
商品,数量,金額
りんご,2,100
みかん,3,200
```

b.csv（UTF-8。後で同じ内容のShift_JIS版でも試す）:

```csv
金額,商品,備考
300,ばなな,試験
400,ぶどう,試験
```

期待: データ4行、元ファイル名列なしなら4列（商品/数量/金額/備考）、元ファイル名列ありなら5列。金額合計1,000。bの数量とaの備考は空欄。スマホでCSVファイルを用意できない場合は内蔵サンプルで画面試験だけ行い、ファイル選択/文字コード試験は未完了にする。

## 手順・合格条件

| 手順 | 期待 |
| --- | --- |
| トップ→ツール→ガイド→プライバシー→トップを移動 | リンクが機能し表示欠けなし |
| 縦向き/横向き、通常/拡大文字で表示 | 操作部が見切れず、表だけ内部横スクロール可能 |
| 内蔵サンプルを実行 | 4行、列対応、空欄補完、金額を検算 |
| 架空a/bを複数選択して結合 | 日本語表示、結果/診断の意味が確認できる |
| 設定またはファイルを変更 | 古い結果が消え保存不可。再実行後に保存可 |
| 結果CSVを保存し、端末のテキスト閲覧で確認 | 保存できBOM付きUTF-8、列/引用符/4行が一致 |
| タブ区切り、引用符内改行、UTF-8とShift_JISの混在 | 読み込み/表示/出力に破損なし |
| 1ファイルだけ、重複/空見出し、閉じない引用符 | エラーを表示、古い結果を保存不可 |
| 10MiB超1ファイル/25MiB超合計 | 読み込む前に容量エラー。実機負荷を無理に増やさず試験停止可能 |
| 見出し/値に文字列 `<img src=x onerror=alert(1)>` | 文字として表示、スクリプトが実行されない |
| 数式対策オン/オフ、半角・全角開始文字 | 実際の出力を記録。全角は現状の未対策候補、合格としない |

実際のExcel/LibreOfficeでの数式解釈・保存後再読み込みは別の検証が必要。スマホのテキスト閲覧だけで数式の安全性を保証しない。解析受信/通信内容は、ネットワーク観測が可能な環境で架空CSVを用い別途確認する。広告ブロックを弱めてまで計測しない。
